# DBeaver SQL Column Lens 3.6.1

**SQL Column Lens** показывает возле значений SQL соответствующие им колонки и помогает читать длинные `INSERT`, `UPDATE`, `ON CONFLICT` и `MERGE`.

```sql
INSERT INTO dm.clients (id, name, inn, status)
VALUES (10, 'ООО Ромашка', '4253000000', 'active');
```

Компактный вид:

```text
id: 10, name: 'ООО Ромашка', inn: '4253000000', status: 'active'
```

Расширенный вид:

```text
id [int] #1: 10, name [varchar] #2: 'ООО Ромашка', ...
```

Расширение не изменяет и не выполняет SQL. Анализ производится локально внутри DBeaver.

## Системные требования

- desktop-версия DBeaver на Eclipse/SWT;
- Java 21 или новее;
- SQL Editor DBeaver;
- папка локального p2-репозитория `sql-column-lens-v3.6.1`.

CloudBeaver не поддерживается.

> **Важно:** версия 3.6.1 исправляет критическую ошибку запуска 3.6.0 (`IDocumentProvider.getDocument(IEditorInput)`). Устанавливайте 3.6.1 поверх 3.6.0 через стандартный мастер обновления.

## Установка через Install New Software

1. Скачайте или клонируйте Git-репозиторий и полностью распакуйте его.
2. В DBeaver откройте `Help → Install New Software…`.
3. Нажмите `Add…`.
4. В поле **Name** укажите `SQL Column Lens 3.6.1`.
5. Нажмите `Local…`.
6. Выберите папку `sql-column-lens-v3.6.1`, внутри которой лежат `artifacts.jar`, `content.jar`, `features` и `plugins`.
7. Нажмите `Add`.
8. Отметьте **DBeaver SQL Column Lens**.
9. Нажмите `Next`, затем ещё раз `Next`.
10. Примите лицензию и нажмите `Finish`.
11. Подтвердите установку неподписанного содержимого, если DBeaver покажет такое предупреждение.
12. Нажмите `Restart Now`.

Когда список компонентов пуст, снимите флажок **Group items by category** и повторно выберите локальный репозиторий.

## Проверка установки

Откройте:

```text
Help → About DBeaver → Installation Details → Plug-ins
```

Найдите:

```text
com.nikbobrovsky.dbeaver.sqlcolumnlens
```

В SQL Editor также должны появиться кнопка **Column Lens**, раздел **SQL Column Lens** в главном меню и команды в `Preferences → General → Keys`.

## Быстрый старт

1. Откройте SQL-файл с поддерживаемым `INSERT`, `UPDATE` или `MERGE`.
2. Нажмите кнопку **Column Lens** в панели SQL Editor.
3. Стрелкой кнопки выберите **Умный режим**.
4. Поставьте курсор на значение или имя колонки.
5. Наведите курсор мыши на парную подсветку для подробной информации.

Обычное нажатие на кнопку включает или выключает расширение. Стрелка открывает меню режимов и действий.

## Режимы отображения

### Умный режим

Режим по умолчанию.

- Двойной клик по одному значению или колонке показывает только этот mapping.
- Устойчивое выделение SQL-фрагмента показывает mappings выбранного фрагмента.
- Без выделения показывается текущий запрос под курсором.
- Промежуточные события двойного клика отменяются и не запускают отображение всего запроса.

### Активное значение

Показывается только mapping под курсором. Это самый лёгкий режим.

### Текущий запрос

Показываются mappings одного `INSERT`, `UPDATE`, `ON CONFLICT` или `MERGE`, в котором находится курсор.

### Весь редактор

Анализируются все поддерживаемые запросы файла. При превышении безопасного порога расширение автоматически показывает текущий запрос.

Команда **Показать все в этой вкладке** временно снимает ограничение только для активной вкладки.

## Исправление двойного клика и набор текста

Версия 3.6.1 стабилизирует изменения selection с небольшой задержкой. Новое событие отменяет предыдущую задачу, поэтому промежуточное выделение DBeaver при двойном клике не успевает построить сотни подписей.

Во время быстрого набора:

- тяжёлый inline-слой не перестраивается после каждого символа;
- status line показывает `Обновление…`;
- анализ запускается после паузы;
- режим **Весь редактор** использует отдельную более длинную паузу;
- устаревший результат фонового анализа не применяется к уже изменённому документу.

## Только видимая область

Опция **Только видимая область** включена по умолчанию. Запрос анализируется полностью, но SWT-подписи создаются только для видимой части редактора и небольшого запаса строк сверху и снизу.

При прокрутке набор подписей обновляется после короткой стабилизации. Активная и закреплённые подписи не теряются из render-plan.

Параметр **Запас строк вокруг видимой области** настраивается в Preferences.

## Многострочный VALUES

Для конструкции:

```sql
INSERT INTO test (id, name, status)
VALUES
    (1, 'A', 1),
    (2, 'B', 0),
    (3, 'C', 1);
```

доступны стратегии:

- **Первая строка + активная** — режим по умолчанию;
- **Только активная строка**;
- **Все строки**;
- **Только подпись под курсором**.

Настройка уменьшает количество повторяющихся inline-labels в больших пакетных `INSERT`.

## Облегчённый режим

Облегчённый режим действует временно для текущей вкладки.

В нём inline-подписи не создаются, но остаются:

- парная подсветка значения и колонки;
- название колонки и позиция в status line;
- тип колонки и обнаруженный вид значения;
- навигационные команды.

Это подходящий вариант для очень больших файлов или слабых рабочих станций.

## Popup со списком mappings

Команда **Список mappings…** открывает поисковое окно:

```text
#   Column                 Value                     Row
1   id                     10                        1
2   name                   'ООО Ромашка'            1
3   status_closed_name     NULL                      1
```

Фильтр ищет по колонке, значению и таблице. `Enter` или двойной клик переходят к выбранному значению.

Команда доступна для назначения собственной комбинации в `Preferences → General → Keys`.

## Навигация

Доступны отдельные команды:

- **Следующее значение**;
- **Предыдущее значение**;
- **Перейти к соответствующей колонке**;
- **Вернуться к значению**;
- **Список mappings…**.

Для каждой команды можно назначить сочетание клавиш через стандартный раздел DBeaver Keys.

## Скрытие и закрепление

Через меню кнопки или контекстное меню SQL Editor можно:

- скрыть текущую подпись;
- скрыть все подписи выбранной колонки в этой вкладке;
- восстановить скрытые подписи;
- скрывать `NULL`;
- скрывать `DEFAULT`;
- закрепить или открепить текущую подпись;
- очистить все закреплённые подписи;
- скопировать название колонки.

Скрытие конкретного значения и закрепления являются временными. После изменения SQL их позиции сбрасываются, чтобы старый offset не применился к другому значению. Скрытые имена колонок сохраняются до закрытия вкладки.

## Hover и совместимость типов

При наведении на парную подсветку отображаются:

```text
Column: status_closed_name
Type: varchar(255)
Position: 16 of 19
Table: dm_esfl_esul.fct_esul
Value: NULL
Detected value: NULL
Compatibility: совместимо
Kind: INSERT VALUES
```

Проверка совместимости консервативная. Она предупреждает только об очевидных случаях, например строковом литерале для numeric-колонки. Сложные выражения помечаются как `не определено`, поскольку окончательное преобразование выполняет СУБД.

Действия для текущего mapping находятся в контекстном меню `SQL Editor → SQL Column Lens`.

## Почему выбран текущий режим

Пункт **Почему выбран этот режим** объясняет эффективное поведение, например:

```text
Найдено 846 mappings, что превышает безопасный порог 300;
временно используется текущий запрос.
```

Там же отображается диагностика вкладки.

## Диагностика

Команда **Диагностика…** показывает:

- версию расширения;
- запрошенный режим и причину эффективного режима;
- состояние облегчённого режима;
- стратегию `VALUES`;
- количество mappings в документе;
- количество реально созданных inline-подсказок;
- время фонового анализа;
- время построения render-plan и слоя;
- последнюю причину refresh;
- состояние typing debounce;
- количество скрытых и закреплённых подписей.

Кнопка **Скопировать** помещает отчёт в буфер обмена.

## Status line

Примеры:

```text
SQL Column Lens · Умный · текущий запрос · 19 подсказок
SQL Column Lens · Активное значение · 1 подсказок · name [varchar] · 2/19
SQL Column Lens · Обновление… · 0 подсказок · фоновый анализ
SQL Column Lens · Безопасный · текущий запрос · 19 подсказок · найдено 846
```

В облегчённом режиме добавляется `без inline`.

## Настройки

Откройте:

```text
Window → Preferences → SQL Column Lens
```

Доступны:

- режим и состояние по умолчанию для новых вкладок;
- стратегия многострочного `VALUES`;
- компактный или расширенный вид;
- inline-подписи и их фон;
- отображение только видимой области;
- запас строк viewport;
- облегчённый режим для новых вкладок;
- status line и парная подсветка;
- загрузка типов колонок;
- позиции и предупреждения;
- фильтры `NULL` и `DEFAULT`;
- задержка стабилизации выделения;
- задержка после набора;
- отдельная задержка тяжёлого режима;
- безопасный порог всего редактора.


## Поддерживаемые конструкции

- `INSERT ... VALUES`;
- многострочный `VALUES`;
- `INSERT ... SELECT`;
- `UPDATE ... SET`;
- tuple assignment в `UPDATE`;
- `ON CONFLICT ... DO UPDATE SET`;
- `MERGE ... WHEN MATCHED THEN UPDATE`;
- `MERGE ... WHEN NOT MATCHED THEN INSERT`.

Динамически сформированный SQL внутри строк, процедурные языки и нестандартный синтаксис отдельных СУБД могут распознаваться частично.

## Обновление и восстановление слоя

- **Обновить подсказки** сбрасывает кэш анализа и повторно анализирует актуальный SQL.
- **Сбросить слой отображения** полностью пересоздаёт inlined painter/support.

Используйте сброс слоя, если после работы стороннего painter или сбоя DBeaver остался пустой отступ либо старая геометрия.

## Удаление

1. Откройте `Help → About DBeaver → Installation Details`.
2. На вкладке **Installed Software** выберите **DBeaver SQL Column Lens**.
3. Нажмите `Uninstall…`.
4. Завершите мастер и перезапустите DBeaver.

## Устранение неполадок

### Компонент не появляется в Install New Software

- выберите папку, где непосредственно лежат `artifacts.jar` и `content.jar`;
- снимите **Group items by category**;
- убедитесь, что архив Git полностью распакован;
- удалите старую запись локального repository из списка Available Software Sites и добавьте её заново.

### Кнопка не появилась

- проверьте bundle в `Installation Details → Plug-ins`;
- убедитесь, что используется SQL Editor, а не простой Text Editor;
- полностью перезапустите DBeaver;
- проверьте Java 21.

### Подписи не появляются

- включите Column Lens через `Alt+Shift+L`;
- выберите поддерживаемый DML-запрос;
- поставьте курсор внутрь запроса;
- проверьте, не включён ли облегчённый режим;
- выполните **Обновить подсказки**.

### После прокрутки показано меньше подписей

Это ожидаемо при включённой опции **Только видимая область**. Отключите её в меню или Preferences, если требуется создать inline-слой для всех mappings выбранного режима.

### DBeaver показывает старую геометрию

Выполните **Сбросить слой отображения**. Перезапуск приложения обычно не требуется.
